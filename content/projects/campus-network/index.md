大一小学校期综合实训项目，使用华为eNSP（Enterprise Network Simulation Platform）模拟器从零搭建完整园区网络，系统性地实践了交换、路由、安全、无线等网络核心技术。

## 项目概述

本项目围绕"一个中型企业园区网"的场景需求，以华为eNSP为平台，分层设计并实现了完整的园区网络架构，涵盖接入层、汇聚层、核心层以及出口安全防护，并延伸至无线网络覆盖。

## 涵盖技术

### 交换技术
- **VLAN/Trunk**：基于802.1Q的VLAN划分与跨交换机Trunk链路配置，实现广播域隔离
- **Eth-Trunk**：多物理链路聚合，提升带宽与链路冗余
- **STP生成树**：防止二层环路，实现链路的冗余备份与自动故障切换
- **DHCP**：部署DHCP服务器实现终端IP地址自动分配

### 路由技术
- **OSPF动态路由协议**：单区域/多区域OSPF配置，实现全网路由互通
- **IPv4编址与路由基础**：IP地址规划、静态路由配置、子网划分

### 安全技术
- **ACL访问控制列表**：基于源/目的IP、端口的流量过滤策略
- **防火墙策略配置**：NGFW下一代防火墙部署，实现安全区域划分、NAT转换、包过滤

### 无线技术
- **WLAN无线网络**：AC+AP架构部署，实现园区无线网络全覆盖

## 项目结构

| 模块 | 对应实验 | 技术要点 |
|------|---------|---------|
| 综合拓扑 | campus network.topo | 全技术融合的园区网总拓扑 |
| VLAN | 以太网交换机与VLAN实验 | Access/Trunk端口、VLAN划分 |
| 链路聚合 | 以太网链路聚合实验 | LACP模式、负载均衡 |
| 生成树 | STP实验 | 根桥选举、端口角色、BPDU |
| OSPF | OSPF实验 | DR/BDR选举、区域划分、路由重分发 |
| ACL | ACL原理与应用实验 | 标准ACL、扩展ACL、时间ACL |
| NAT | NAT实验 | 静态NAT、动态NAT、NAPT |
| 防火墙 | 防火墙配置实验 | 安全区域、包过滤、NAT策略 |
| DHCP | 网关与DHCP实验 | DHCP中继、地址池配置 |
| WLAN | WLAN实验 | AC+AP、SSID、无线安全 |
