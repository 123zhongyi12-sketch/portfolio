# 钟懿个人作品集网站 — 设计文档

> 日期: 2026-07-27
> 状态: 待审核

---

## 1. 项目概述

为钟懿构建一个面向求职的个人作品集网站，展示其云计算/IT技术能力、项目经验与认证成就。网站以不同URL路由对应不同求职方向（售前/运维/云安全），面试官打开即看到完整的单方向作品集，无需切换。

## 2. 技术栈

| 层 | 技术 |
|---|------|
| 框架 | Next.js 16 (App Router, static export) |
| 语言 | TypeScript |
| 样式 | Tailwind CSS v4 |
| 内容 | JSON 数据文件 + Markdown 介绍 |
| 部署 | Vercel (免费版, zhongyi.vercel.app) |
| 图标 | lucide-react |
| 字体 | Geist Sans (Vercel 默认) |

## 3. 站点结构

```
zhongyi.vercel.app/
├── /                         # 首页 → 自动重定向到 /presales（主投方向）
├── /presales                 # 售前方向 - 独立完整站
├── /ops                      # 运维方向 - 独立完整站
├── /cloud-security           # 云安全方向 - 独立完整站
└── /projects/
    ├── /resume-assistant     # AI面试助手项目详情
    ├── /cloud-architecture   # 14天云架构设计
    ├── /huawei-ict           # 华为ICT大赛全球一等奖
    └── /...                  # 其他项目
```

**关键原则**：每个方向站点之间无导航链接。面试官看到的每一个URL都像是一个为该公司定制的专属站点。

## 4. 页面设计

### 4.1 首页（以售前为例）

从上到下：
1. **导航栏**：Logo（姓名） | 项目 | 联系我（极简，无方向切换）
2. **主视觉区**：头像 | 姓名 | 一句话定位 | 简短口号
3. **关于我**：个人简介（带关键词标签）
4. **精选项目**：3-4个项目卡片，可点击进入详情
5. **认证荣誉**：华为认证/奖项墙（走马灯或网格展示证书图片）
6. **技术栈**：技能标签云
7. **联系**：邮箱/GitHub/微信等

### 4.2 简历页结构

每个方向（/presales, /ops, /cloud-security）共享相同模板，但内容差异化：

| 模块 | 差异化策略 |
|------|-----------|
| 一句话定位 | 方向定制 |
| 个人介绍 | 侧重点不同（售前→沟通/方案；运维→架构/部署；安全→合规/防护） |
| 项目排序 | 各方向优先展示最相关的项目 |
| 技能展示 | 排序和权重不同 |

### 4.3 项目详情页（核心）

**代码类项目布局（左右分栏）：**
```
左栏（约35%）：项目文件树
  - 从 /content/projects/{name}/files/ 下的预生成结构数据渲染
  - 可展开/折叠文件夹
  - 点击文件可高亮（预览内容，非完整打开）

右栏（约65%）：内容区（从上到下）
  - 项目名称 + GitHub链接
  - 项目介绍文字（Markdown渲染）
  - 技术栈标签
  - 核心亮点（数据/成果）
  - 截图/架构图轮播（可点击放大）
  - "我的总结"（自定义心得）
```

**非代码类项目布局（单栏）：**
```
- 项目标题 + 归属方向
- 背景/赛事介绍
- 我的角色与贡献
- 成果展示（证书图片/现场照片轮播）
- 我的收获/总结
```

## 5. 视觉风格

- **主题**：科技暗色（深色背景 #0a0a0f/#0f0f1a）
- **主色调**：蓝色/青色渐变（#3b82f6 → #06b6d4 或 #6366f1 → #8b5cf6）
- **点缀**：发光效果、鼠标悬停高亮、微动效
- **排版**：清晰层级，简洁现代
- **呼应**：云服务控制台/IDE风格的科技感，呼应华为云背景

## 6. 内容管理（用户可手改）

所有内容集中在 `data/` 和 `content/` 文件夹，用户只需修改以下文件：

| 文件路径 | 管理内容 | 操作方式 |
|---------|---------|---------|
| `data/profile.json` | 姓名、简介、头像路径、联系方式 | 修改JSON字段 |
| `data/resumes.json` | 各方向版本的介绍文本、项目排序、技能列表 | 修改JSON字段 |
| `data/projects.json` | 项目列表、技术栈标签、排序 | 修改JSON字段 |
| `content/projects/{project-name}/` | 每个项目的介绍md文件 + 图片资源 | 替换md + 拖入图片 |
| `content/projects/{project-name}/images/` | 项目截图、架构图、证书图片 | 放入图片文件 |

用户无需接触任何代码。加新项目时只需：
1. 在 `data/projects.json` 加一条记录
2. 在 `content/projects/{new-name}/` 下放介绍文字和图片

## 7. 部署

- **平台**：Vercel (Hobby 免费版)
